<h1 align="center"># Weather Focus App 🌤️

A clean and interactive weather application that allows users to check the current weather for any city worldwide.

## Features

- Search weather by city name
- Displays current temperature, humidity, wind speed, and weather description
- Dynamic weather icons based on conditions
- Responsive design suitable for both desktop and mobile
- Auto-updates with the current time of the last fetch

## Technologies Used

- HTML, CSS, JavaScript
- OpenWeatherMap API for live weather data
