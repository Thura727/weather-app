## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Displays current temperature, humidity, wind speed, and weather description
- 🌦️ Dynamic weather icons based on conditions
- 📱 Fully responsive design for desktop and mobile
- ⏰ Auto-updates with the latest fetch time
- 🏙️ Default city displayed on load (`Yangon`)

---

## 🛠️ Technologies Used

- HTML, CSS, JavaScript
- [OpenWeatherMap API](https://openweathermap.org/api) for live weather data
